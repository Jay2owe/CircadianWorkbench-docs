    Complete action reference¶

    This page is generated from the live registry and documents all 84 callable actions. The signature and parameter tables are therefore the contract enforced by the runner, not a parallel handwritten list.

    All successful actions return data, warnings, provenance, and an equivalent replay script. File-writing actions place files under root; source recordings remain read-only.

    group_contrasts¶

    Declared group contrasts of pooled per-unit tables: reduce to the replication unit, test, and correct within each declared family.

    cw.call("group_contrasts", contrast_tables, contrast_specs, contrast_missing_columns={}, contrast_resamples=2000, contrast_seed=20260902)
    Name Type Required Default Units Meaning
    contrast_tables object yes — - Pooled tables by name, each a list of records with the replication-unit columns (stem and identity for cells, stem for movies, subject for subjects), the group_by column and every metric named by a contrast. A null table is refused by name in the result, not guessed.
    contrast_specs array yes — - Declared contrasts: name, table, metrics, group_by, groups, unit (cell, movie or subject), test (mannwhitney, kruskal, welch_t, anova, wilcoxon, paired_t, signed_rank), optional aggregate (median or mean, required when units repeat), family, window, correction (benjamini_hochberg, bonferroni, sidak, none), alpha and description.
    contrast_missing_columns object no {} - Per pooled table, the movie stems missing each column, so a metric absent from some movies is reported as a refusal rather than silently tested on the rest.
    contrast_resamples integer no 2000 - Bootstrap resamples for each effect-size percentile interval.
    contrast_seed integer no 20260902 - Seed of the one random generator shared by every bootstrap interval in the call, so the table is reproducible as a whole.

    Result access: declared.

    Figure views: No Result.plot adapter; use the declared result or the separate export action.

    sample_contrast¶

    Permutation contrast of one finite aggregate per independent or matched biological sample; never frames, pairs or cells.

    cw.call("sample_contrast", reference_values, target_values, contrast_settings, contrast_design='independent', contrast_metrics=None)
    Name Type Required Default Units Meaning
    reference_values array yes — measurement units One finite aggregate per independent biological sample (or per original member of each match) in the reference condition. Never frames, pairs or cells.
    target_values array yes — measurement units One finite aggregate per independent biological sample (or per matched member) in the target condition.
    contrast_settings object yes — - Declared evidence: method none, independent_sample_permutation or matched_sample_permutation with the declared population (independent_samples or matched_samples), min_samples/min_pairs, resamples, seed and an interval block (none, independent_bootstrap or paired_bootstrap). A state design adds metrics, contrasts, alpha and multiple_testing.
    contrast_design string no "independent" - independent (exchangeable samples between conditions), matched (labels exchangeable only within each declared match) or state (a frozen state-summary comparison).
    contrast_metrics array no null - State design only: the saved summaries the caller offers, so a declared metric outside that list is refused.

    Result access: declared.

    Figure views: No Result.plot adapter; use the declared result or the separate export action.

    association¶

    Association evidence under a declared null: truncated time-shift, complete lag search, sample pairing permutation, rank pattern or exact sign test.

    cw.call("association", association_kind, association_reference, association_question, association_target=None, association_support=None, association_lags_hours=None, association_unit_ids=None, association_alpha=0.05)
    Name Type Required Default Units Meaning
    association_kind string yes — - same_time (truncated time-shift test of two traces), lag (complete declared lag search with optional stationary-bootstrap delay uncertainty), sample (pairing permutation over sample aggregates), pattern (Spearman association of paired sample effects) or sign (exact sign frequency across sample summaries).
    association_reference array yes — hours and measurement units For same_time and lag: records with hours, processed_value and within_range for the reference trace. For sample and pattern: one aggregate per independent sample. For sign: the signed sample summaries.
    association_question object yes — - The declared question: enabled, statistic (pearson or spearman) and an evidence block naming the method and its justification; lag adds range_hours, resolution_hours and peak_resolution; sign uses evidence method sample_sign_test; pattern uses method, statistic, justifications, min_samples, resamples and seed.
    association_target array no null hours and measurement units The target trace records (same_time, lag) or target sample aggregates (sample, pattern); unused by sign.
    association_support object no null observations and hours Trace sufficiency floor for same_time and lag: min_observations, min_span_hours and max_gap_hours after truncation.
    association_lags_hours array no null hours lag only: the complete declared lag grid in hours, which must match range_hours and resolution_hours exactly.
    association_unit_ids array no null - pattern only: one unique sample identifier per paired effect.
    association_alpha number no 0.05 - sign only: one minus the exact Clopper-Pearson interval's confidence.

    Result access: declared.

    Figure views: No Result.plot adapter; use the declared result or the separate export action.

    spatial_permutation¶

    Random-label evidence for a declared spatial question: complete cell marks permuted among fixed locations.

    cw.call("spatial_permutation", spatial_marks, spatial_reference_indices, spatial_target_indices, spatial_distances, spatial_near, spatial_question)
    Name Type Required Default Units Meaning
    spatial_marks array yes — measurement units One [reference, target] pair of finite characteristic marks per complete eligible cell; the two marks stay together under permutation.
    spatial_reference_indices array yes — - Row index into spatial_marks of the reference cell of each pair.
    spatial_target_indices array yes — - Row index into spatial_marks of the target cell of each pair; never the same cell as its reference.
    spatial_distances array yes — caller's spatial units Fixed measured distance of each pair, in the caller's spatial units.
    spatial_near array yes — - Per pair, whether it counts as near for the near_minus_far effect.
    spatial_question object yes — - statistic (absolute_difference or squared_difference), distance_effect (spearman or near_minus_far) and an evidence block: method none or mark_location_permutation with null_model exchangeable_marks_fixed_locations, exchangeability_justification, min_cells, n_resamples, seed and alternative.

    Result access: declared.

    Figure views: No Result.plot adapter; use the declared result or the separate export action.

    segmented_regression¶

    One predeclared before/after mean contrast within a series, fitted by feasible GLS with stationary autoregressive errors.

    cw.call("segmented_regression", regression_baseline, regression_target, regression_settings, regression_operation='mean', regression_alpha=0.05)
    Name Type Required Default Units Meaning
    regression_baseline array yes — hours and measurement units Ordered original observations before the anchor: records with raw_value, relative_hours (negative), sequence_index, observation_id, raw_valid, clock_valid and optional frame_index.
    regression_target array yes — hours and measurement units Ordered original observations from the anchor onward (relative_hours zero or positive), continuing the baseline sequence without a gap.
    regression_settings object yes — - method none or segmented_glsar with estimand (modelled_window_mean_change or baseline_trend_adjusted_change), baseline_trend (constant or linear), response_model (level or level_and_slope), ar_order, optional min_observations_per_window and both justification texts.
    regression_operation string no "mean" - The window summary under test; only mean has a conditional-mean model, other summaries are refused with their descriptive change retained.
    regression_alpha number no 0.05 - Two-sided level of the contrast's t interval.

    Result access: declared.

    Figure views: No Result.plot adapter; use the declared result or the separate export action.

    Name Type Required Default Units Meaning
    agreement_records array yes — - One record per unique observation: id, unit, first and second. Share the unit across movies from one biological sample. Detections are strictly true, false or null for an unavailable test.
    independent_units boolean no false - Explicit confirmation that unit identifiers name independent biological samples; false permits descriptive counts and agreement only.
    agreement_confidence number no 0.95 fraction Coverage of one conservative Hoeffding interval for equal-sample mean observed kappa, conditional on nonconstant jointly-tested margins; strict fraction between zero and one.

    agreement_permutations integer no 9999 pairings Maximum randomly sampled pairings for the optional sample association, at least 99; enumerate all pairings when feasible.
    agreement_seed integer no 20260910 - Nonnegative seed for the optional sample-fraction permutation test.

    normalize¶

    Normalise one selected trace with an explicit, reproducible method.

    cw.call("normalize", recording, config=None, normalization_method='minmax', target_min=-1.0, target_max=1.0, reference_value=None, reference_start_hours=None, reference_end_hours=None, reference_statistic='mean', standard_deviation_ddof=0, detrended=False, envelope_floor_fraction=0.1)
    Name Type Required Default Units Meaning
    recording recording spec yes — - The record to analyse: {'path': 'data/m01.awd'} (a bare path string also works), {'demo': true} for the built-in deterministic record, {'inline': {'filename': ..., 'text': ...}} for tabular text, {'trace': {'hours': [...], 'values': [...], 'name': ...}} for one elapsed-time trace, or {'channels': {'hours': [...], 'values': {'reporter_a': [...], 'reporter_b': [...]}}} for several measurements from one subject. Versioned recording_snapshot specs are self-contained numeric inputs for replaying in-memory Recording objects; they do not invoke a raw-activity importer.
    config object no null - Partial scientific settings. Omitted or None values use the shared installed defaults; invalid fresh values are rejected. Run describe_config for names, meanings, units, bounds and choices. Explicitly load old saved mappings with load_saved_settings to report compatibility conversions.
    normalization_method string no "minmax" - Transformation to apply. Canonical choices are none, mean_center, median_center, zscore, robust_zscore, robust_scale, own_mean, own_daily_total, minmax, max_abs, reference_delta, fold_change, delta_over_reference, log2_fold_change, percent_of_reference, percent_change, envelope and pre_treatment_cycle. Aliases include range for minmax, extreme or to_extreme for max_abs, z for zscore, dff for delta_over_reference, and fold for fold_change.
    target_min float no -1.0 normalised units Lower output bound for minmax range scaling; ignored by other methods.
    target_max float no 1.0 normalised units Upper output bound for minmax range scaling; must exceed target_min.
    reference_value float no null recording units Explicit baseline for reference_delta, fold_change, delta_over_reference, log2_fold_change, percent_of_reference, percent_change or pre_treatment_cycle. Use this or a reference time window, never both.
    reference_start_hours float no null hours Inclusive start of the baseline window, in hours from the selected recording start. Must be paired with reference_end_hours.
    reference_end_hours float no null hours Inclusive end of the baseline window used to calculate the reference. Must exceed and be paired with reference_start_hours.
    reference_statistic string no "mean" - How a reference time window is reduced: mean or median.
    standard_deviation_ddof integer no 0 - Degrees of freedom removed from the z-score standard-deviation divisor: 0 for a population, 1 for a sample.
    detrended boolean no false - Whether inputs are already baseline-subtracted.
    envelope_floor_fraction float no 0.1 fraction For envelope normalisation, return missing values after the fitted oscillation envelope falls below this fraction of its starting amplitude. Must lie from 0 inclusive to 1 exclusive.

    Config: all keys and defaults.
