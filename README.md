# Circadian Workbench documentation

The public guide at https://jay2owe.github.io/CircadianWorkbench-docs/ matches
the documentation bundled with Circadian Workbench 0.15.0.

[Download the Windows installer](https://github.com/Jay2owe/CircadianWorkbench-Releases/releases/tag/v0.15.0)
or [install the Python package](https://pypi.org/project/circadian-workbench/0.15.0/).

This repository contains the generated static site and public figure derivatives.
The application source and private figure masters are maintained separately.
